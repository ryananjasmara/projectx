# projectx

An Expo (React Native) app using file-based routing via [expo-router](https://docs.expo.dev/router/introduction).

## Setup

```bash
npm install
```

## Running the app

```bash
npm run start      # Metro bundler, choose a platform from the terminal
npm run ios
npm run android
npm run web
```

## Storybook

Component stories live next to their component (e.g. `components/text.stories.tsx`).

```bash
npm run storybook
npm run storybook:ios
npm run storybook:android
```

## Linting

```bash
npm run lint
```
